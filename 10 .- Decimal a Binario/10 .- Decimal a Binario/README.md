## Programa 10
### Nombre
Conversion a binario indirecta
### Descripción
Convertir un numero entero no negativo a su representacion binaria usando dos metodos que se llaman mutuamente
### Lenguaje
C#
### IDE
Visual Studio
### Conceptos utilizados
- Variables
- Métodos
- Recursividad
- Condicionales
- Entrada y salida de datos
